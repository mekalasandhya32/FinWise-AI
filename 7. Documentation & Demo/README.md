## Demo Script
1. Open the published URL.
2. Walk the **Home** page — hero, features, stats, testimonials, FAQ.
3. Run the **EMI Calculator** — slide principal / rate / tenure, show
   real-time recompute + amortization split.
4. Fill the **Loan Eligibility** form with a strong profile, submit,
   show the verdict + score bar + recommendations.
5. Repeat with a weak profile to show risk-band handling.
6. Open the **Credit Score Analyzer**, show the meter + factor cards.
7. Chat with the **AI Advisor** — ask for a 50/30/20 budget, watch tokens
   stream in with markdown lists.
8. Show the corresponding Google Sheet rows for the submitted forms.
